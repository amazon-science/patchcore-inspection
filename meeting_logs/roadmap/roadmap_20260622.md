## スライド 11：ブロッカー／未解決の設計課題

1. **map 解像度の基準**：`target_map_size: teacher` で統一予定（A_S を A_T サイズへ補間）。Teacher map の H_map×W_map は patchsize/層構成依存 → precompute 時に実測して固定。
2. **Teacher score スケール**：category 依存。z-score か min-max かを D1 で決め打ちし、評価まで一貫させる（設計書 §21.5）。
3. **正常のみ蒸留の限界**：S2 は異常マップを強く出す学習信号が不足する懸念（設計書 §22）。S3（疑似異常）の必要性を D6 の数値で判断。
4. **公平な効率比較**：Teacher は memory bank search 時間込みで計測。faiss GPU/CPU の条件を meta.json に明記。
5. **既存 distill(M0-M4) との関係**：**全く別実験として完全分離**。`distill_map`（マップ蒸留）を今後の主軸とし、`distill`（M0-M4 スコア蒸留）は現状維持で温存。横並び比較は行わない。
